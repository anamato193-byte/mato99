# تطبيق حارس التطبيقات الذكي (Smart App Locker) - مشروع أندرويد كامل (Kotlin)

هذا المشروع البرمجي الكامل لنظام **Android** يحقق كافة المتطلبات على مستوى نظام التشغيل الفعلي للهاتف:
1. **قفل كافة تطبيقات الهاتف بالبصمة أو الرمز السري (PIN)** باستثناء التطبيقات التي تحددها في القائمة البيضاء (المسموح بها).
2. **زر اختصار مركزي كبير في منتصف الشاشة** داخل التطبيق لتفعيل/إيقاف وضع القفل الشامل بضغطة واحدة (مع اشتراط البصمة عند الإيقاف) وفتح نافذة الوصول السريع للتطبيقات المسموح بها.
3. **منع حذف التطبيق تماماً إلا بالبصمة**: يعتمد على صلاحية مسؤول الجهاز (`DeviceAdminReceiver`) بالإضافة إلى مراقبة شاشة الحذف والإعدادات عبر خدمة (`AccessibilityService`)، بحيث إذا حاول أي شخص الدخول إلى إعدادات الهاتف لإلغاء تثبيت التطبيق أو إيقاف صلاحية المسؤول، تظر له شاشة البصمة فوراً وتمنعه من الحذف.

## طريقة استخراج ملف APK وتثبيته على الهاتف:
### الطريقة الأولى (بدون كمبيوتر - عبر GitHub مجاناً):
1. ارفع ملفات هذا المجلد إلى مستودع جديد على حسابك في GitHub.
2. سيقوم ملف البناء التلقائي المرفق (`.github/workflows/build_apk.yml`) بتجميع التطبيق تلقائياً خلال دقيقتين.
3. ادخل إلى قسم **Actions** ثم حمل ملف `app-debug.apk` وثبته على هاتفك مباشرة.

### الطريقة الثانية (عبر برنامج Android Studio):
1. افتح المجلد داخل برنامج **Android Studio**.
2. اضغط على **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
3. انقل ملف `APK` الناتج إلى هاتفك وثبته، ثم امنحه صلاحية **الظهور فوق التطبيقات** و **إمكانية الوصول (Accessibility)** و **مسؤول الجهاز (Device Admin)** لمنع الحذف.
